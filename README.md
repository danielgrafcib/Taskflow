# TaskFlow - Application de Gestion de Projets

## Description
TaskFlow est une application de gestion de projets complète développée en Java, offrant une interface moderne et intuitive pour la gestion des tâches, des projets et des équipes.

## Fonctionnalités Principales

### 1. Écran de Connexion (LoginFrame)
- Interface de connexion élégante avec dégradé de couleur
- Système d'authentification sécurisé
- Validation des identifiants utilisateur
- Design moderne avec effets visuels

### 2. Tableau de Bord Principal (DashboardPanel)
- Vue d'ensemble des métriques importantes :
  - Nombre total de tâches
  - Tâches en retard
  - Taux d'achèvement global
- Indicateurs de performance avec graphiques
- Interface intuitive avec cartes d'information

### 3. Gestion des Projets (ProjectPanel)
- Création et modification de projets
- Suivi de l'état des projets
- Gestion des dates de début et de fin
- Visualisation de l'avancement

### 4. Gestion des Tâches (TaskPanel)
- Création et assignation de tâches
- Suivi de l'état des tâches
- Filtrage par projet et statut
- Définition des priorités
- Interface de gestion complète

### 5. Assignation des Tâches (AssignmentPanel)
- Interface d'assignation des tâches aux utilisateurs
- Gestion des affectations par projet
- Historique des assignations
- Vue claire des responsabilités

### 6. Indicateurs de Performance (KPIPanel)
- Graphiques et statistiques détaillés
- Taux de complétion par projet
- Répartition des tâches par statut
- Analyse de la performance des équipes
- Visualisation des tendances

### 7. Historique (HistoryPanel)
- Suivi complet des activités
- Historique des modifications
- Traçabilité des actions
- Filtrage par période

### 8. Gestion des Utilisateurs (UserManagementPanel)
- Création et gestion des comptes utilisateurs
- Attribution des rôles
- Interface d'administration complète
- Gestion des permissions

### 9. Gestion des Rôles (RoleManagementPanel)
- Définition des rôles et permissions
- Administration des droits d'accès
- Interface de gestion des rôles
- Configuration des autorisations

## Interface Utilisateur
- Design moderne et épuré
- Navigation intuitive avec barre latérale
- Thème clair avec accents de couleur
- Composants interactifs et réactifs
- Notifications et retours visuels
- Interface responsive et adaptative

## Technologies Utilisées
- Java
- Swing (Interface graphique)
- FlatLaf (Thème moderne)
- MySQL (Base de données)
- MigLayout (Gestionnaire de mise en page)
- JFreeChart (Graphiques)
- iTextPDF (Génération de rapports)
- Commons DBUtils (Gestion base de données)

## Sécurité
- Authentification sécurisée
- Gestion des sessions utilisateur
- Contrôle d'accès basé sur les rôles
- Validation des données

## Configuration Requise
- Java Runtime Environment (JRE) 8 ou supérieur
- MySQL Server
- Mémoire RAM : 4 Go minimum
- Espace disque : 500 Mo minimum
