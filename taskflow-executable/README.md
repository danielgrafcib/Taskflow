# TaskFlow

TaskFlow est une application de gestion de projets développée en Java. Elle permet de gérer efficacement les projets, les tâches et les équipes avec une interface moderne et intuitive.

## Installation

1. Assurez-vous d'avoir JDK 8 ou supérieur installé.
2. Téléchargez les dépendances nécessaires dans le dossier `lib`.
3. Configurez le fichier `config.properties` selon vos besoins.

## Exécution

Pour exécuter l'application, utilisez le fichier JAR généré dans le dossier `target` après la compilation. Vous pouvez également créer un exécutable .exe en utilisant Launch4j avec le fichier `launch4j.xml`.

## Fonctionnalités

- Gestion des projets et des tâches
- Interface utilisateur moderne
- Suivi des performances et des KPIs
